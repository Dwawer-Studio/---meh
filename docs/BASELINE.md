نظيفة، ثم يحذف اللقطة المؤقتة.

## ما يحميه خط الأساس

- سلامة صياغة ملفات JavaScript.
- تكوين الرزمة وعدد البطاقات ومعرّفاتها.
- قواعد المطابقة الأساسية الحالية.
- اتجاه الدور والالتفاف حول الطاولة.
- دورة العضو: إنشاء واختيار وتسجيل فوز وخسارة ثم حذف.
- دورة لعبة محلية: بدء وتوزيع وسحب ورمي وإعادة تشغيل.
- وجود جميع الصور والمراجع المحلية.
- تطابق مفاتيح الترجمة العربية والإنجليزية.
- وجود عناصر DOM المشار إليها وعدم تكرار المعرّفات.
- توازن أقواس CSS وترتيب تحميل السكربتات.
- صحة HTML وCSS وفق المدققات المعيارية المضافة وحدودها المعلنة.
