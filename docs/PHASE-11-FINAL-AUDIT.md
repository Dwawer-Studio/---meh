## الهدف

تراجع هذه المرحلة نتائج المراحل 0–10 كوحدة واحدة، وتفصل بوضوح بين اكتمال
معالجة العيوب المتفق عليها وبين قرارات النشر العامة التي لم يأذن المستخدم
بتنفيذها بعد. لا يكفي وجود وثيقة سابقة لإغلاق بند؛ يجب أن يملك البند اختبارًا
قابلًا للتشغيل أو تحققًا مباشرًا مناسبًا.

## الفجوات التي كشفتها المراجعة

كانت ملفات التشغيل والاختبارات متوافقة، لكن README بقي خلف حالة المشروع في
ثلاث نقاط:

- لم يذكر اللعب الجماعي أو تقرير المرحلة 10.
- وصف المشروع بأنه بلا مكتبات خارجية رغم استخدام PeerJS.
- أوحى بأن السحب لا يحدث إلا عند غياب بطاقة مناسبة، بينما القرار المعتمد يسمح
  بالسحب بدل الرمي دائمًا.

صُححت النقاط الثلاث، وأضيفت بوابة تمنع رجوعها. كما تمنع البوابة الجديدة إدخال
`skip` أو `todo` إلى ملفات الاختبار، وتتحقق من وجود وثائق جميع المراحل وربطها
من README.

كشف التحقق اليدوي كذلك حالة طرفية في الهاتف: إذا فُتحت لوحة المطور على سطح
المكتب ثم صُغرت النافذة، يبقى محتوى اللوحة فوق اللعبة بينما زر فتحها السري
مخفي دائمًا. أضيف زر إغلاق أصلي داخل اللوحة نفسها، باسم عربي وإنجليزي ومؤشر
تركيز، وأصبحت رحلتا الهاتف العمودي والأفقي تفتحان اللوحة وتغلقانها ضمن
Playwright.

## الحدود المقصودة وليست ادعاءات إنجاز

- لا يوجد TURN مخصص بعد؛ الاتصال عبر شبكات NAT المقيدة يحتاج قرار تشغيل ونشر.
- نموذج اللعب ودي والمضيف هو صاحب الحالة الموثوقة؛ لا توجد مصادقة بشرية أو
  خادم تحكيم تنافسي.
- مورد Azure غير مجهز والنشر معطل تلقائيًا عمدًا. لا تُعد النسخة جاهزة للنشر
  العام قبل اختيار الاستضافة وتحديث أسرارها وإجراء اختبار شبكات عام.

هذه الحدود موثقة وليست عيوبًا مخفية، ولا تمنع دمج التحسينات أو التشغيل المحلي.

## بوابات الإغلاق

```bash
npm run test:final
npm run check
npm run check:clean
npm audit --audit-level=high
```

## نتيجة الإغلاق في 2026-08-28

- `npm run test:final`: ثلاثة اختبارات ناجحة، 0 فشل، 0 متجاوز، و0 مؤجل.
- `npm run check`: 115 اختبار Node و5 اختبارات Chromium ناجحة، مع نجاح صياغة
  JavaScript ومدققي HTML وCSS.
- `npm run check:clean`: ثبّت 249 حزمة من ملف القفل في لقطة Git معزولة، أعاد
  البوابة الكاملة بنجاح، ثم أثبت بقاء اللقطة نظيفة.
- `npm audit --audit-level=high`: صفر ثغرات.
- التحقق اليدوي أنشأ عضوًا، غيّر إعدادًا بلوحة المفاتيح، وزّع 7 بطاقات لكل
  لاعب، سحب إلى 8، وصل إلى الفوز، وأعاد المباراة. عند `390 × 844` ظهر زر
  إغلاق لوحة المطور وأغلقها، وبقيت عناصر اللعبة الأساسية ظاهرة.
- تحذير التثبيت الوحيد هو إهمال `node-domexception@1.0.0` المتعدي عبر
  `peer@1.0.2 → node-fetch → fetch-blob`. الاعتماد تطويري لخادم الإشارة في
  الاختبار، وليس ضمن ملفات تشغيل المتصفح، ولا يسجل npm ثغرة له. يُراجع عند
  صدور نسخة خادم PeerJS تزيل السلسلة.
