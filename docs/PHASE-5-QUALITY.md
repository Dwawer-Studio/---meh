# المرحلة 5 — جودة القالب وتنظيم CSS

## النطاق

تغلق هذه المرحلة استثناءات الجودة التي سُجلت صراحة في خط الأساس ولم تكن
ضمن مراحل الأمان أو الاعتمادية أو قواعد اللعب أو إمكانية الوصول:

- `QUALITY-01`: منع الأنماط المضمنة وتفضيل عناصر HTML الأصلية المناسبة.
- `QUALITY-02`: منع المحددات المكررة وترتيب خصوصية CSS ترتيبًا يمكن للمدقق
  التحقق منه.

لا تغيّر هذه المرحلة قواعد اللعبة أو تدفقها؛ هدفها جعل الاستثناءات المؤجلة
بوابات فشل إلزامية ومنع عودتها مستقبلًا.

## حالة الفشل قبل الإصلاح

بعد تفعيل القواعد المؤجلة فشل التحقق كما هو متوقع بـ18 مخالفة:

- مخالفة HTML واحدة بسبب نمط مضمن لصورة الشعار.
- 17 مخالفة CSS: أربع مجموعات من المحددات المكررة و13 حالة ترتيب خصوصية.

## الإصلاحات المنفذة

### HTML

- نُقلت خصائص صورة الشعار من السمة `style` إلى الصنف `logo-image`.
- فُعلت قاعدتا `no-inline-style` و`prefer-native-element` بمستوى `error`.
- أضيفت اختبارات تمنع تعطيل القواعد أو إعادة سمة `style` إلى القالب.

### CSS

- دُمجت التعريفات المكررة للأزرار الأساسية والثانوية، ومحتوى الطاولة، وزر
  لوحة المطور.
- رُتبت قواعد البطاقات والأزرار وحالات التعطيل والتخطي وفق الخصوصية من دون
  تغيير النتيجة البصرية المقصودة.
- أزيل تعريف عرض زائد في شاشة الأونلاين؛ تمدد Flex الافتراضي يحافظ على عرض
  الأزرار داخل اللوحة.
- فُعلت قاعدتا `no-descending-specificity` و`no-duplicate-selectors`، وأضيف
  اختبار يمنع تعطيلهما بصمت.
