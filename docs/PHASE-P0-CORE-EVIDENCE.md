# تقرير المرحلة P0 — تثبيت القلب وصناعة الدليل

التاريخ: 2026-08-28

## النتيجة

فُصلت قواعد «مِهْ» الثابتة عن كتالوج البطاقات ووصفة الرزمة، وأصبحت الرزمة
الحالية ذات تعريف تنفيذي صريح. أضيف replay حتمي واختبار 1000 مباراة كاملة،
ومخطط قياس بموافقة، وطابور offline، وأعلام منتج مطفأة افتراضيًا، وعقد اقتصاد
تاماشي ونموذج تهديد. لم يُنفذ متجر أو محفظة أو شراء حقيقي في هذه المرحلة.

## حدود صريحة

- الموافقة على القياس ليست واجهة مستخدم بعد؛ قبل الموافقة لا يُحفظ أي حدث.
- لا يوجد sink إنتاجي أو إرسال شبكي للأحداث في P0.
- PeerJS مناسب للاختبار الودي، وليس مصدر حقيقة لعملة أو تصنيف.
- أرقام أسعار تاماشي ومعدل كسبها غير مختلقة هنا؛ تُستخرج في P4 من زمن الفتح
  المستهدف وتجارب حقيقية.
- نجاح المحاكاة يثبت الحتمية والسلامة البنيوية، لا يثبت المتعة أو التوازن البشري.

## طريقة التحقق

```bash
npm run check
npm run check:clean
```

تكتمل المرحلة فقط بعد نجاح البوابتين وتسجيل نتائج التنفيذ الفعلية أدناه في نفس
الفرع.

## نتائج التحقق الفعلية

- `npm run check`: نجح — 135/135 اختبار Node و5/5 اختبارات متصفح.
- `npm run check:clean`: نجح من لقطة Git مؤقتة وبـ`npm ci` مستقل —
  135/135 اختبار Node و5/5 اختبارات متصفح، ثم بقيت اللقطة نظيفة.
- اختبار replay ضمن البوابتين شغّل 1000 مباراة كاملة مرتين، مع تطابق الأفعال
  والبصمتين النهائيتين والحفاظ على 60 بطاقة فريدة في كل مباراة.
