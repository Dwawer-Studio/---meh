# تقرير المرحلة P4 — كتالوج البطاقات وتاماشي

التاريخ: 2026-08-28

الحالة: `Engineering Complete / Validation Deferred`

لا تصبح الحالة `Engineering Complete` إلا بعد نجاح كل البوابات المدرجة أدناه،
ومنها محاكاة 100 ألف مباراة ولقطة تثبيت نظيفة، ثم تطابق رأس الفرع المحلي
والبعيد. ولا تعني الحالة الهندسية أن بطاقة مستقبلية ممتعة أو أن سعرًا صالح
للسوق؛ الاختبارات البشرية والميدانية واختبارات المتاجر الحقيقية محفوظة في
`docs/DEFERRED-VALIDATION-REGISTER.md`.

## حدود المرحلة غير القابلة للتفاوض

- عدد تعريفات الإنتاج الجديدة: **صفر**.
- تعريفات البطاقات الـ22 الحالية، وصفة `classic-60-v1` ذات 60 بطاقة، الآرت،
  قواعد المطابقة والسحب والدور والفوز لم تتغير.
- لا opcode جديد، ولا بطاقة مدفوعة حصرية، ولا packs أو wager أو cash-out أو
  تحويل بين اللاعبين.
- تاماشي وفتح البطاقة والـfriendly recipe خلف أعلام مستقلة. الأسعار الحالية
  معايرة هندسية مؤقتة ومغلقة عن الإنتاج.
- `verified_iap` مغلق ما لم يُحقن verifier حقيقي؛ لا يوجد في هذه المرحلة
  اتصال إنتاجي بـApple أو Google ولا تخزين receipt خام.
- public quick play يبقى على وصفة classic موحدة؛ ملكية بطاقة لا تغيّر يد صاحبها
  ولا تمنحه احتمال سحب مختلفًا.

## قائمة الإغلاق الهندسي

- [x] سجل كتالوج immutable يتحقق من العقد الثنائي اللغة والوصولية والقرار
  والـcounterplay وحالات الحافة وميزانية الاستبدال ومسار الكسب باللعب.
- [x] envelope موقّع Ed25519 مع canonical JSON، إصدار forward-only، ومنع تعديل
  أو حذف أي تعريف أو وصفة embedded، ورجوع فوري إلى classic.
- [x] content flag لكل بطاقة، free rotation محدد، ورفض عميل قديم أو ناقص
  capability قبل إدخاله وصفة لا يفهمها.
- [x] وصفة ودية مشتركة وحتمية: مساهمة واحدة كحد أقصى لكل مقعد، واستبدال 1:1
  من الفئة وميزانية القوة نفسيهما، وقفل الوصفة والمشاركين عند البدء.
- [x] دفتر تاماشي append-only مع wallet revision، idempotency، وقفل ذري للرصيد
  والإيصال والفتح والتسوية في MemoryStore وPostgreSQL.
- [x] المكافأة مشتقة من مباراة خادمية فقط؛ leaver أو أي مقعد استُخدم له timeout
  تلقائي لا يأخذ منحة المباراة، وفارق الفائز 16.67%، مع سقف cohort والحساب بلا
  streak يومي.
- [x] شراء مباشر ثابت السعر بلا duplicate أو paid-exclusive، وIAP يأخذ المبلغ
  من SKU/verifier الخادمي ويفشل مغلقًا عند غياب موفّر حقيقي.
- [x] مصالحة startup وكل خمس دقائق ويدوية تفحص السلسلة والرصيد والفتح والإيصال
  والتسوية؛ أي فرق يجمد كل mutation اقتصاديًا مع إبقاء اللعب والقراءة.
- [x] واجهة اختيارية عربية/إنجليزية تعرض الرصيد والعدالة والأثر والرد والسعر
  والدوران المجاني والوصفة المشتركة، بلا اعتراض أول جلسة أو زر شراء للكلاسيك.
- [x] migration additive، حذف/إخفاء هوية، backup/restore، telemetry محدود بلا
  account أو receipt أو transaction، وعقود تشغيل وتهديد ورجوع.
- [x] أصلحت بوابة المحاكاة حلقة افتتاح نادرة عند seed `80736`: إذا وُزعت كل
  البطاقات العادية في الأيدي، تُستعاد واحدة مع تعويض صاحبها بدل الدوران غير
  المحدود. بقيت قاعدة الافتتاح العادي، 7 بطاقات لكل لاعب، ومجموع 60 كما هي،
  وتُرفض أي وصفة مستقبلية لا تحتوي نوع افتتاح صالح.
- [x] سجل الاختبارات البشرية والميدانية المؤجلة مكتمل بشروط نجاح مقفلة.
- [x] محاكاة 100 ألف مباراة classic تنتهي بصفر loop/card loss/replay mismatch
  وصفر unknown definition.
- [x] `check:clean` النهائي ينجح من تثبيت مستقل، ثم ينشأ commit ويُرفع الفرع
  ويتطابق رأسا local/upstream.

## عقد العدالة والربحية

فتح البطاقة يمنح اللاعب حق اقتراحها في غرفة ودية فقط. الخادم يبني رزمة واحدة
مشتركة يراها الجميع، ثم تُخلط وتوزع بلا علاقة بصاحب البطاقة. الوصول الدائم
متاح باللعب، والدوران المجاني يسمح بالتجربة، والشراء المالي—بعد تحقق المتجر
لاحقًا—يختصر زمن الفتح ولا يبيع احتمال فوز أو قوة حصرية.

النموذج المؤقت يمنح 100 للإكمال، و20 للمشاركة الصحية، و20 للفوز. السعر المركزي
هو 120 مضروبًا في 8 أو 12 أو 16 مباراة مستهدفة. هذه ليست أسعار إطلاق؛ تبقى
مقفلة حتى تنجح `P4-E01` ببيانات بشرية فعلية.

نجاح هذه المرحلة تلقائيًا.

## ما بقي مؤجلًا عمدًا وليس نجاحًا مزعومًا

- فهم البطاقة واختبار المتعة الأعمى لكل تعريف: `P4-H01` و`P4-H02`.
- معايرة الاقتصاد الحقيقية لـ14 يومًا: `P4-E01`.
- كشف AFK/collusion وfalse suppression ميدانيًا: `P4-A01`.
- Apple/Google sandbox وduplicate/refund: `P4-I01`.
- طرح تعريف واحد في 5% من الغرف الودية وتمرين الرجوع: `P4-R01` و`P4-O01`.

لذلك لا تُستخدم عبارة `Validated`، ولا يفتح شراء نقدي أو public/ranked أو سعر
إنتاج أو بطاقة إنتاج جديدة قبل إغلاق البنود التابعة لها.
