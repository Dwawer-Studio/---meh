# قرارات قواعد اللعبة

اعتمدت القرارات المرتبطة بقواعد اللعب في المرحلة 3، وأصبحت محمية باختبارات
`RULE-01` و`RULE-02`. يبقى قرار بنية TURN قرار نشر وتشغيل، لا قرار قواعد.

| القرار | القاعدة المعتمدة | الحالة |
|---|---|---|
| السحب مع وجود بطاقة قابلة للعب | مسموح؛ يمكن للاعب اختيار السحب بدل الرمي | معتمد — المرحلة 3 |
| تكديس عقوبات السحب | الردود الصالحة حصراً: `draw2` و`draw4Wild` و`meh` و`counterAttack` و`phantom`؛ لا تشترط مطابقة اللون أثناء العقوبة | معتمد — المرحلة 3 |
| البطاقة الافتتاحية | بطاقة `normal` فقط، لذلك لا يبدأ تأثير خاص بصورة صامتة | منفذ ومختبر — المرحلة 3 |
| التخلص من ورقة إضافية | تُنقل البطاقة إلى المرمي تحت بطاقة التأثير الحالية؛ لا تُحذف من دورة الرزمة | منفذ ومختبر — المرحلة 3 |
| تأثير الورقة الإضافية | لا ينفذ تأثيرها ولا تغير اللون النشط لأنها لم تُلعب كحركة مستقلة | معتمد — المرحلة 3 |
| مدة شوقر | دورة طاولة كاملة؛ تنتهي عند عودة الدور إلى لاعب شوقر | منفذ ومختبر — المرحلة 3 |
| فانتوم | يلغي عقوبة السحب المعلقة ويمنح درعاً يستهلكه أول سحب لاحق على اللاعب | معتمد — المرحلة 3 |
| الثقة بالمضيف | الإصدار الحالي لعب ودي؛ المضيف هو صاحب الحالة الموثوقة | معتمد — المرحلة 1 |
| الاتصال في الشبكات المقيدة | PeerJS الافتراضي بلا TURN مخصص | مؤجل إلى قرار النشر العام |
