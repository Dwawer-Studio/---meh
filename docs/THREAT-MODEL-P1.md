# نموذج التهديد — P1 الدعوة والجلسة الاجتماعية

التاريخ: 2026-08-28

## حدود الثقة

المضيف والمتصفحات وPeerJS ورمز الغرفة القصير كلها خارج حد الثقة الاقتصادي.
المضيف سلطة اللعب الودي فقط. لا نتيجة من هذه البنية تمنح تاماشي أو ملكية بطاقة
أو تصنيفًا. يبقى نموذج P0 وعقد ADR-0002 نافذين.

## التهديدات والضوابط

| التهديد | الأثر | الضابط في P1 | المتبقي لـP2 |
|---|---|---|---|
| تخمين رمز غرفة من خمسة أحرف | دخول غير مدعو أو إزعاج | مساحة أحرف مقيدة، حد 4 مقاعد، رفض بعد البدء | رمز عشوائي طويل وموقع، rate limit وحظر |
| سرقة عقد المقعد | انتحال لاعب منقطع | رمز عشوائي في `sessionStorage`، تحقق قائمة سماح، لا بث | هوية خادمية وتدوير/إبطال |
| تسريب الرمز أو العقد في القياس | انتهاك خصوصية أو استيلاء | مخطط يحظر `roomCode` والاسم، واختبار snapshot عام | تنقيح خادمي ومراجعة سجلات |
| تسريب اليد عبر snapshot أو السجل | غش | snapshot الطاولة عام بلا يد؛ السجل يصف الحركة العامة فقط | بروتوكول خادمي تفاضلي |
| رسالة شبكة خبيثة | XSS أو تغيير غير قانوني | تحقق نوع/طول/قائمة سماح، وعرض بـ`textContent` | مصادقة ورسائل موقعة وحدود سرعة |
| قطع عميل لدوره | تجميد المجلس | عقد 15 ثانية، ثم بوت يكمل اليد | سياسة AFK خادمية ومراقبة |
| اختفاء المضيف | فقد الجلسة | استعادة انقطاع الإشارة المؤقت | ترحيل سلطة أو خادم صاحب سلطة |
| QR خارجي يسجل الدعوة | تسريب الرابط | توليد QR محليًا بلا طلب شبكة | لا شيء ما دام المورد مثبتًا ومدققًا |
| تلاعب المضيف بالنتيجة | غش/سك مكافأة | لا اقتصاد ولا تصنيف في P1 | تحقق خادمي قبل تاماشي |

## تحقق منفذ

- snapshot العام لا يحتوي `ownerId` أو `seatToken` أو موعد العقد.
- الدعوة التالفة والممتلئة وغير المتاحة تبقى أخطاء قابلة للاسترجاع.
- العميل العائد لا يتجاوز سعة الغرفة، والدخيل لا يستبدل مقعدًا أثناء المباراة.
- سجل الحركة الوارد مقيد النوع والطول ولا يقبل HTML.
