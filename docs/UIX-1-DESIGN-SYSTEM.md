# UIX-1 — نظام التصميم التقني والهوية

التاريخ: 2026-08-29

الحالة: `Implemented / Production Foundation Active`

الفرع: `codex/uiux-u1-design-system`

## النتيجة

تحول دستور UIX-0 من نموذج مرجعي إلى طبقة إنتاج تحملها اللعبة نفسها. لم تعد
ألوان Dwawer وخط IBM Plex Sans Arabic ومبادئ الأسطح والحركة قيماً داخل وثيقة؛
أصبحت ملفات مشتركة مرتبطة بـ`index.html` قبل بدء إعادة تركيب الشاشات.

تظل بنية الشاشة القديمة مؤقتاً حتى تستبدلها UIX-2 وما بعدها. هذا فصل مقصود:
UIX-1 يثبت المفردات والمكونات والبوابات، وUIX-2 يبدأ إعادة التأليف من دون خلق
نظام بصري ثانٍ.

## المصدر التنفيذي

| الملف | المسؤولية |
|---|---|
| `ui/tokens.css` | اللون، الخط، المسافة، الشكل، الظلال، مدد الحركة |
| `ui/foundations.css` | الخط العام، focus، الأيقونة، السلم الطباعي، وجسر الانتقال المؤقت |
| `ui/components.css` | الأسطح، الأزرار، الحقول، tabs، dialogs، status، loading، skeleton |
| `ui/motion.css` | acknowledgment، enter، lift، وبديل reduced motion |
| `ui/accessibility.css` | 44px targets، 200% text، skip link، forced colors، واستجابة الحوار |
| `assets/ui/icons.svg` | مفردات SVG النظامية المشتركة |
| `ui/fixture/` | معرض تفاعلي يستخدم ملفات الإنتاج نفسها |

## العقد المنقول من UIX-0

- الألوان الأساسية مطابقة حرفياً لـ`docs/uiux-u0/tokens.json`.
- أحمر الهوية الصافي ليس خلفية لنص أبيض صغير؛ الأزرار الممتلئة تستخدم
  `brand.signalDeep` بنسبة تباين معتمدة.
- تاماشي له لون دلالي مستقل، ولا يتحول إلى ذهب كازينو.
- ألوان اللعبة الأربعة محجوزة للقواعد والبطاقات فقط.
- الخط محلي بوزني Regular وSemiBold ولا توجد شبكة في مسار تحميله.
- شبكة 4px، radii بقيم 12/22/34px، وfocus بسمك 3px.
- الحد الأدنى المتكرر 44px، والفعل الأساسي 48px.
- مدد acknowledgment وmicro والشاشة لا تتجاوز عقد UIX-0.

## معرض الحالات

الرابط المحلي:

```text
/ui/fixture/index.html?locale=ar&scale=100&motion=full
```

المعاملات:

- `locale=ar|en` يثبت RTL/LTR والنصين.
- `scale=100|200` يختبر تمدد النص الحقيقي.
- `motion=full|reduced` يعرض الحركة أو البديل الساكن.

المعرض يغطي: primary/secondary/disabled/icon buttons، حقل طبيعي وحقل خطأ،
tabs/tabpanel، badges وتاماشي، status success/warning، loading، skeleton، empty،
ثلاثة أسطح، وحوار يعيد focus إلى سببه بعد الإغلاق.

## بوابة UIX-1

أدلة البوابة الآلية:

```bash
npm run validate
npm run test:uiux-u1
npx playwright test tests/e2e/uiux-u1.spec.js
```

تتحقق من:

1. تحميل ملفات النظام داخل الإنتاج بالترتيب الصحيح.
2. مطابقة tokens للدستور السابق وحساب نسب التباين.
3. وجود الخط محلياً وتحميله فعلياً في المعرض والتطبيق.
4. AR/EN، RTL/LTR، 100%/200%، وتقليل الحركة.
5. عدم وجود overflow أفقي في الحالات الأربع عند `393×852`.
6. أن كل button/input ظاهر لا يقل عن 44×44 CSS px.
7. عمل tabs والحوار بلوحة المفاتيح واستعادة focus.
8. وجود أكثر من 20 رمز SVG مطلوباً وعدم وجود system emoji في ملفات UIX-1.
9. عدم تعديل Core أو Catalog أو أي أصل بطاقة عبر بوابة UIX-0 المستمرة.

## ما لم تنفذه هذه الشريحة

- لم تعد تركيب الرئيسية أو الغلاف أو الدعوة؛ هذا UIX-2.
- لم تغيّر الطاولة أو آرت البطاقة؛ هذا UIX-3 مع Core Lock.
- لم تغيّر المتجر والاقتصاد؛ هذا UIX-5.
- لم تضف أصواتاً أو haptics؛ هذا UIX-6.
- لم تحذف CSS القديم بعد، لأن UIX-7 يحذفه فقط بعد استبدال كل مستهلك.
