# UIX-2 — غلاف التطبيق والرئيسية والدخول

التاريخ: 2026-08-29

الفرع: `codex/uiux-u2-app-shell`

الحالة: `Implemented`

## النتيجة

صار الدستور البصري UIX-0 ونظام UIX-1 واجهة الإنتاج الفعلية لـSplash، اختيار
العضو، الرئيسية، مركز اللعب، التعليمات، الإعدادات، الدخول أونلاين، والدعوة.

لم يتغير قلب اللعب، وصفة الـ60 بطاقة، أو أي ملف تحت `assets/cards/`. اللوبي،
الطاولة، النتائج، والمتجر لم يُعد تصميمها هنا؛ لها شرائح UIX-3–5.

## المسارات المنفذة

```text
لاعب حالي: Splash → الرئيسية → العب الآن → الطاولة
أول جلسة: Splash → عضو جديد → الرئيسية → اللعب
مدعو: ?join=ABCDE&v=1 → مقعدك محجوز → اجلس على الطاولة
```

- `#play-btn` يبدأ جولة محلية مباشرة. الخيارات الثانوية في «خيارات اللعب».
- «البطاقات» مخفية حتى يكمل العضو مباراة، وتتاح خدمة الكتالوج، ويُفعل
  `card_catalog` و`tamashi_wallet`.
- الرابط الصالح يتجاوز الرئيسية؛ والتالف يحافظ على سياق الدعوة ويعرض خطأً قابلًا للاسترداد.

## هندسة التنفيذ

| الملف | المسؤولية |
|---|---|
| `ui/shell.css` | إطار الشاشات، Splash، الألواح، والتنقل |
| `ui/screens/home.css` | تأليف رأسي وأفقي مستقلان للرئيسية |
| `ui/screens/entry.css` | العضو، مركز اللعب، التعليمات، الإعدادات، الدعوة، والأونلاين |
| `game/game-screen.js` | سجل المتصفح، `popstate`، الرجوع، واستعادة التركيز |
| `game/game-profile.js` | دخول العضو وتحديث هويته في الغلاف |
| `game/game-invite.js` | الدعوة العميقة وتماسك الاسم/التسمية |
| `game/game-catalog.js` | سياسة تأخير ظهور البطاقات |
| `i18n.js` | نسخ AR/EN متكافئة للسطوح الجديدة |

`tools/serve.js` يخدم SVG/WOFF2/PNG بأنواع MIME الصحيحة، فالأيقونات والخط أصول إنتاج
محلية وليست مجرد نموذج.

## قرارات الجودة

- Hero يعرض أصول البطاقات نفسها؛ لا إعادة رسم أو recolor أو crop دائم.
- الوضع الأفقي composition مستقل وليس تصغيرًا للرأسي.
- Splash موروث من motion primitives وله بديل `prefers-reduced-motion`.
- الرجوع يستخدم history الحقيقي ويعيد التركيز إلى العنصر المفتاح.
- بقي emoji التواصل وصور الأعضاء؛ أزرار وحالات النظام الجديدة تستخدم SVG.
- لم يُعد تصميم المتجر بشكل موهم؛ وأُجل تصميمه الحقيقي إلى UIX-5.

## بوابة المرحلة

| الشرط | الدليل |
|---|---|
| فعل واحد إلى اللعب | E2E ينقر `#play-btn` ويثبت ظهور 7 بطاقات |
| الدعوة إلى المقعد | E2E يثبت أن `invite-screen` هي النشطة مباشرة |
| back/focus | E2E يختبر العودة و`#instructions-btn`، `#play-options-btn`، `#menu-settings-btn` |
| المتجر مخفي أولًا | UIX-2 وauthoritative يثتان الإخفاء ثم الفتح بعد نتيجة |
| مصفوفة الهاتف | 360×800، 393×852، 430×932، 844×390، 932×430 بلا overflow أو أهداف صغيرة |
| لا أصل مفقود | E2E يفشل عند صورة مكسورة أو HTTP محلي ≥400 |
| Core/البطاقات مقفلة | diff عن UIX-1 لـ`deck.js`، `shared/match-reducer.js`، `assets/cards/` فارغ |

## التحقق البشري المؤجل

بقرار مالك المنتج لم يُنفذ الاختبار البشري ولم يُعد نجاحًا وهميًا. بندا P1-H01 وP1-H02 في
`docs/DEFERRED-VALIDATION-REGISTER.md` يغطيان فهم الدخول وزمن الدعوة إلى المقعد، وسينفذان على
الواجهة النهائية بعد UIX-7.
