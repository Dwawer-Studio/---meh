# UIX-3 — طاولة اللعب والبطاقة

التاريخ: 2026-08-29

الفرع: `codex/uiux-u3-game-table`

الحالة: `Implemented / Human Validation Deferred`

## النتيجة

أصبحت الطاولة المرجعية في UIX-0 واجهة الإنتاج الفعلية، بتأليف مستقل للرأسي
والأفقي بدل تصغير نفس المشهد. مركز القرار يعرض السحب والمرمى واتجاه اللعب
واللون النشط، وتدخل المقاعد واليد وحالة الدور في تركيب واحد واضح.

لم يتغير قلب اللعبة أو وصفة الرزمة أو أي ملف تحت `assets/cards/`. أزيل القص
القديم من عرض الصورة فقط؛ كل بطاقة تستخدم ملف WebP الأصلي كاملًا بـ`contain`.

## ما نُفذ

- شريط طاولة خفيف يعرض السياق ورقم الجولة وسجل الحركة.
- ثلاثة مقاعد خصوم وهوية اللاعب مع العدد والـactive/skip state.
- مركز لعب حي: draw/discard، اتجاه، turn action، timer، active color، والقرارات.
- يد مرئية بوضوح مع `playable` و`selected` و`disabled`، وتأكيد/إلغاء اختياريين.
- وضع يد كثيفة بعد 10 بطاقات بتمرير أفقي مقصود، بدل قص البطاقات خارج الشاشة.
- سجل حركة dialog مع إدارة focus، وإرشاد أول دور منخفض الهيمنة.
- نصوص وحالات AR/EN متكافئة، مع SVG لأفعال النظام وبقاء emoji للتواصل والهوية.
- مسار `prefers-reduced-motion` يلغي حركات الطاولة غير الضرورية.

## المراجعة البصرية

رُوجعت نسخة الإنتاج الحية على 393×852 و932×430، بما فيها أول دور، بطاقة
محددة، شريط التأكيد، أسماء المقاعد، وصور البطاقات غير المقصوصة. المقارنة كانت
مع مرجعي UIX-0 للرأسي والأفقي، لا مع CSS القديم.

## التحقق البشري المؤجل

بقرار مالك المنتج، لم تُدّعَ نتيجة بشرية. مهام تحديد صاحب الدور خلال ثلاث
ثوانٍ، معرفة البطاقة القابلة للعب، والعثور على «ليش صار كذا؟» مسجلة في
`docs/DEFERRED-VALIDATION-REGISTER.md` لتنفذ بعد UIX-7.
