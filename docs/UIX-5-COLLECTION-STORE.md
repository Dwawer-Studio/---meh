# UIX-5 — مجموعة البطاقات والمتجر وتاماشي

التاريخ: 2026-08-29

الفرع: `codex/uiux-u5-collection-store`

الحالة: `Implemented / Human Validation Deferred`

## النتيجة

تحول سطح P4 الوظيفي إلى خزانة بطاقات قابلة للفهم والاستخدام، من دون تغيير
تعريف بطاقة واحدة أو صورة واحدة أو قاعدة لعب. تفصل الشاشة بوضوح بين «المتجر»
للتوسعات المعتمدة و«مجموعتي» للبطاقات المتاحة، وتشرح قبل أي شراء أن البطاقة
تدخل وصفة الرزمة المشتركة ولا تمنح المشتري يداً أقوى أو أفضلية فردية.

المسار المحلي لا يعرض شراءً نقديًا ولا يفعّل `verified_iap`. تاماشي المعروض
هو الرصيد السلطوي، ومصادر الكسب تأتي من سياسة الخدمة نفسها وليست أرقامًا
مغروسة في الواجهة.

## ما نُفذ

- غلاف إنتاجي بهوية Dwawer للبطاقات وتاماشي بدل لوحة المتجر القديمة.
- رصيد تاماشي ظاهر دائمًا، مع مصادر الإكمال والمشاركة والفوز من السياسة
  السلطوية وشرح شرط المباراة الموثقة.
- فصل مخزون التوسعات عن المجموعة؛ البطاقات الكلاسيكية الـ22 لا تظهر للبيع.
- معرض مجموعة ثنائي على الهاتف ومتجاوب على الشاشات الأكبر، مع نسبة اكتمال
  أصلية عبر عنصر `progress` دلالي.
- مرشحات: الكل، الشخصيات، الحركة، القوى، والبطاقات الخاصة.
- عرض صور البطاقات الأصلية بـ`object-fit: contain` ومن دون filter أو transform
  أو قص أو تعديل للملفات.
- فتح تفاصيل البطاقة من المعرض؛ لا يوجد زر شراء داخل بلاطة البطاقة.
- حوار قرار يعرض بالترتيب: الأثر، القرار، الرد المضاد، معنى الوصول، التجربة
  المجانية عند توفرها، السعر بتاماشي، ثم فعل الفتح.
- تعطيل فعل الفتح عند نقص الرصيد، وتحديث الرصيد والحالة من الخدمة بعد النجاح.
- إدارة تركيز كاملة للحوار: نقل التركيز، حصر Tab، Escape، النقر على الخلفية،
  استعادة المشغّل، وعزل الشاشة الخلفية بـ`inert`.
- حالات صريحة للتحميل والخطأ القابل لإعادة المحاولة والمتجر الفارغ والمرشح
  الفارغ، بالعربية والإنجليزية.
- تقديم المتجر/المجموعة قبل شرح الاقتصاد على الهاتف كي لا يضيع السطح الأساسي
  أسفل لوحة المكافآت.

## بوابة المرحلة

| الشرط | الدليل |
|---|---|
| الـ22 في المجموعة فقط | الخدمة السلطوية وE2E يثبتان متجرًا بعدده 0 ومجموعة بعدد 22 |
| لا زر شراء بلا توسعة | المعرض والمتجر الفارغ كلاهما بصفر `.catalog-buy` |
| السياق قبل الشراء | ترتيب DOM واختبار المتصفح يضعان الأثر/القرار/counterplay والسعر قبل الزر |
| لا أفضلية فردية | نص الوصول يصرح أن الفتح يسمح باقتراح البطاقة للرزمة المشتركة المتوازنة |
| التجربة المجانية | بطاقة التوسعة التجريبية تعرض حالة Free Rotation وشرح عدم الفتح الدائم |
| لا نقد محلي | النص ظاهر و`verified_iap: false`، ولا سعر نقدي أو وسيلة دفع في السطح |
| الصور بلا تعديل | `contain` بلا crop/filter/transform، وكل صورة محملة، وhash الأصول مطابق |
| الحالات | loading/error/retry/empty/filter-empty موجودة ومختبرة |
| الوصولية | progress أصلي، tabs دلالية، أهداف ≥44px، حوار modal مع حصر/استعادة focus |
| الأجهزة | 393×852 و430×932 و844×390 و932×430 بلا overflow أفقي |
| Core/آرت | manifests الخاصة بالقلب وكل صور البطاقات مطابقة byte-for-byte |

```bash
npm run test:uiux-u5
```

البوابة المخصصة تشمل عقد UIX-5 وعقد P4 للواجهة، وسيناريوهات المتصفح الخاصة
بالمجموعة/التوسعة/الحالات، إضافة إلى مسار الخدمة السلطوية الحقيقي. لا تغني عن
`npm run check` و`npm run check:clean`.

## المراجعة البصرية

رُوجعت واجهة الإنتاج الحية مع الخدمة المحلية في العربية والإنجليزية على سطح
المكتب، 393×852، و932×430. أدى الفحص إلى إصلاح تباين نص المتجر الفارغ، إزالة
أثر focus غير المقصود عن عنوان الشاشة، حسم تعارض تبويب قديم، تقديم المحتوى على
الهاتف، وإخفاء شريط تمرير المرشحات مع إبقاء التصنيف التالي ظاهرًا جزئيًا.

## التحقق البشري المؤجل

بقرار مالك المنتج، لم تُدّعَ نتيجة بشرية أو سوقية. أضيف UIX-H08 لفهم المجموعة
والفلاتر وUIX-H09 لفهم تاماشي وعدم بيع الأفضلية إلى
`docs/DEFERRED-VALIDATION-REGISTER.md`. تبقى P4-H01 لاختبار فهم كل بطاقة جديدة،
وP4-E01 لمعايرة اقتصاد تاماشي، وP4-I01 للشراء الحقيقي، شروطًا مانعة للإطلاق.

## الحد الصادق

- لا توجد توسعة إنتاجية منشورة في الكتالوج الحالي؛ لذلك المتجر الفارغ هو
  الحالة الصحيحة، وليس نقصًا مخفيًا.
- لم تُثبت بعد متعة أي بطاقة جديدة أو صلاحية سعرها أو فهم اللاعبين للاقتصاد.
- choreography والصوت واللمس النهائي من نطاق UIX-6.
- visual regression الشامل وpseudo-localization وإزالة CSS القديم من UIX-7.
