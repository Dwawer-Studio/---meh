# UIX-6 — الإخراج الحركي والصوتي

التاريخ: 2026-08-29

الفرع: `codex/uiux-u6-feedback`

الحالة: **Engineering Complete / Human Validation Deferred**

## النتيجة

أصبحت الاستجابة الحسية في مِهْ منظومة واحدة قابلة للمقاطعة، لا مجموعة مؤثرات
متفرقة. مدير `FeedbackDirector` يقرر ملف العرض `full / reduced / battery`
ويعرض الحركة فقط؛ لا يملك حالة مباراة ولا يغير مؤقت الدور أو قواعد البطاقة.

## ما أُنجز

### 1. Choreography مترابطة

- لعب البطاقة: إقرار فوري، lift، مسار قصير، settle خلال 260ms، ثم أثر البطاقة.
- السحب: مسار ورقي 280ms، وعند تقليل الحركة يتحول إلى نبضة عداد بلا انتقال
  مكاني.
- العقوبة: نبضتان صوتيتان/اهتزازيتان قصيرتان، شارة `+N`، وسبب نصي قرب
  اللاعب لمدة 3 ثوانٍ مع «ليش صار كذا؟».
- انتقال الدور: خروج المقعد السابق 120ms ووصول المقعد الجديد 180ms، من دون
  تأخير مؤقت الدور أو إعادة حركة قديمة بعد العودة من الخلفية.
- النتيجة: تنكمش الدائرة وتفتح الورقة خلال 420ms، مع بقاء CTA قابلاً للاستخدام
  فوراً، ومن دون confetti أو particle storm.
- تعرض النتيجة حالة تاماشي الصادقة: الجولة المحلية لا تمنح رصيداً، والجولة
  الموثقة تعرض أن التسوية تُؤكد في الرصيد؛ لا يُختلق مبلغ غير صادر من الخادم.

### 2. صوت mute-first بثلاث قنوات

- الافتراضي: `Master=false`, `Music=false`, `SFX=true`، ولذلك لا ينشأ
  `AudioContext` ولا يخرج صوت قبل opt-in صريح لـMaster.
- `sound: true` القديم لا يُعامل كموافقة؛ لأنه كان افتراضياً في النسخة
  السابقة. تمت إضافة هجرة توافقية تجعل `sound` مرآة لـ`soundMaster`.
- Master وMusic وSFX مفصولة بعقد صوتي وGain مستقل لكل قناة.
- موسيقى الطاولة هادئة واختيارية، تتوقف خارج الطاولة وفي الخلفية ووضع البطارية.
- مفردات SFX ثابتة: `tap-soft`, `card-lift`, `card-settle`,
  `turn-ready`, `penalty-double`, `round-resolve`.
- مزامنة الحساب تقبل المفاتيح الجديدة ولا تفقد إعدادات اللاعب بين الأجهزة.

### 3. وصول وطاقة وأمان حسي

- haptics تبقى مغلقة افتراضياً، وكل استدعاء محمي بـ
  `settings.haptics === true`.
- جميع أنماط الاهتزاز أقل من أو تساوي 250ms.
- أزيل وميض الشاشة كامل المساحة واستبدل بنبضة حدّ واحدة 360ms ذات
  `animation-iteration-count: 1`؛ الحد التنفيذي للوميض هو صفر.
- أزيل إنشاء 90 عنصر confetti؛ النتيجة الحالية لا تنشئ جسيمات DOM.
- `prefers-reduced-motion` يحافظ على بوابة UIX-1 العامة عند 1ms، ولا يسمح
  بـ120ms إلا للـcrossfade/outline الضروريين في UIX-6.
- وضع البطارية يلغي الحركة غير الضرورية كلياً، ويترك النص والحالة والـCTA.
- شاشة البداية لم تعد تحجب التطبيق 1.9 ثانية: 420ms كحد أقصى، و220ms مع
  تقليل الحركة، وصفر في وضع البطارية.

## حدود الأداء المقفلة

| الحدث | Full | Reduced | Battery | هل يحجب الإدخال؟ |
|---|---:|---:|---:|---|
| انتقال شاشة | 320ms | 120ms crossfade | 0 | لا |
| لعب بطاقة | 260ms | 120ms crossfade | 0 | لا يتجاوز بوابة الأثر القديمة |
| سحب بطاقة | 280ms | 120ms counter pulse | 0 | لا |
| انتقال دور | 180ms | 120ms outline | 0 | لا |
| نبضة أثر | 360ms، مرة واحدة | 120ms | 0 | لا |
| لحظة نتيجة | 420ms | 120ms crossfade | 0 | لا؛ CTA فوري |
| Splash | 420ms | 220ms | 0 | ضمن الحد |

## بدائل الصوت والحركة

| المعنى | البديل المرئي/النصي |
|---|---|
| وصول النقرة | press state وحافة focus |
| رفع/استقرار البطاقة | البطاقة المحددة والمرمى والسجل |
| السحب | انتقال/نبضة عداد وحدث السجل |
| أصبح دورك | المقعد النشط، مؤشر الاتجاه، و`aria-live` |
| العقوبة | `+N`، شريط السبب، وسجل «ليش صار كذا؟» |
| نهاية الجولة | عنوان النتيجة، الترتيب، حالة تاماشي، وأزرار المتابعة |

## التحقق البشري المؤجل

أضيف `UIX-H10` لفهم كل feedback مع الكتم وتقليل الحركة، و`UIX-H11`
لإثبات عدم وجود خرج مفاجئ وفهم فصل Master/Music/SFX. شروطهما مقفلة في
`docs/DEFERRED-VALIDATION-REGISTER.md` ولا يُعد الاختبار الآلي بديلاً عنهما.
