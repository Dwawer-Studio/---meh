# UIX-7 — الصلابة والطرح

التاريخ: 2026-08-29

الفرع: `codex/uiux-u7-hardening`

الحالة: **Engineering Complete / Human Validation Deferred**

## النتيجة

أُغلقت إعادة بناء الواجهة هندسياً على النظام الجديد وحده. حُذف ملف CSS القديم
والـflag الانتقالي، وقُفلت مصفوفة الأجهزة والحالات، والوصولية، والأداء، والصور
المرجعية كبوابات مستودع قابلة لإعادة التشغيل. لم تتغير قواعد اللعبة أو وصفة
الـ60 بطاقة أو تعريفات الكتالوج أو أي بايت من آرت البطاقات.

## ما أُنجز

### 1. إزالة الطبقة القديمة فعلياً

- حُذف `style.css` وتوقف `index.html` وأدوات الفحص عن تحميله أو التحقق منه.
- أزيلت `ui-v2` و`data-ui-system` من الإنتاج والـfixture والاختبارات؛ لا يوجد
  flag يخفي بقاء واجهتين متوازيتين.
- أصبحت وحدات `ui/` هي المصدر الوحيد للهوية والتخطيط والحالات، مع استكمال
  قواعد runtime التي كانت تعتمد ضمناً على الملف القديم.
- لا تحميل شبكي لخط أو أيقونة أساسية؛ الوزن العادي فقط في critical preload،
  والصور غير الحرجة lazy/async.

### 2. مصفوفة أجهزة وحالات مقفلة

تغطي البوابة الأحجام العشرة المقفلة:

| السياق | الأحجام |
|---|---|
| عربي عمودي | 360×800، 393×852 |
| إنجليزي عمودي | 360×800، 430×932 |
| هاتف أفقي | 844×390، 932×430 |
| لوحي | 768×1024، 1024×768 |
| سطح مكتب | 1366×768، 1440×900 |

وفي كل إطار تُفحص normal، reduced motion، colorblind، نص 200%، pseudo-locale،
loading/error/empty، والطاولة في ready/selected/decision/penalty/result. ترفض
البوابة overflow، clipping، overlap، صورة مكسورة، مفتاح ترجمة خام، أو هدف
تفاعل أصغر من 44px.

أغلقت المصفوفة عيوباً فعلية قبل الاعتماد: قص حافة مروحة البطاقات على الهاتف،
تزاحم الإيموجي مع تأكيد البطاقة، عرض جذر بقي 1280px بعد تصغير نافذة محملة،
وضيق تكوين نتيجة سطح المكتب. لم يُخفّض معيار الفحص لتمريرها.

### 3. Visual regression مستقر

- عشر لقطات مرجعية فعلية في
  `tests/e2e/uiux-u7-visual.spec.js-snapshots/` تغطي الشاشات والاتجاهات
  واللغتين.
- أزيلت من اللقطة فقط رسالة الترحيب العابرة التي لها بوابة UIX-6 مستقلة،
  وحُيّد موضع مؤشر الفأرة كي لا يُقفل hover عشوائي داخل baseline.
- جُددت الصور بعد حذف cascade القديم ومراجعة النتيجة الفعلية، ثم نجح تشغيل
  مستقل 10/10 دون `--update-snapshots`.

### 4. لغة ووصول

- pseudo-localization لكاملي قاموسي AR/EN مع تمديد لا يقل عن 30% وحفظ
  placeholders مثل `{name}` و`{n}`.
- axe WCAG 2 A/AA و2.1/2.2 AA يغطي الملف الشخصي والرئيسية والطاولة والقرار
  والنتيجة في الاتجاهين بلا مخالفة.
- مسار لوحة مفاتيح فعلي يغطي skip link، التنقل، بدء الجولة، اختيار بطاقة،
  التأكيد، وبنية النتيجة، مع فحص accessibility tree.
- قارئ الشاشة الحقيقي ليس مستبدلاً بـaxe؛ بقي `UIX-H12` مؤجلاً صراحة.

### 5. ميزانيات الأداء

- الاستجابة المرئية المحلية تحت CPU ×4: أقل من 100ms.
- كل من impact وpenalty وresult يُقاس كمهمة مستقلة كما يحدث في اللعب؛ صفر
  long task فوق 50ms في البوابة، مع تكرار فحص الأداء ثلاث مرات أثناء التدقيق.
- CSS أقل من 250KB، JavaScript أقل من 1.2MB، الخطوط أقل من 300KB، وheap
  المقاس أقل من 64MB.
- لا animation حاجبة تتجاوز 450ms، ولا خط/أيقونة حرجة من origin خارجي.
- القياس الميداني على أجهزة Android فعلية بقي في `UIX-H13` ولم يُدّعَ آلياً.

## أدلة البوابة

- `npm run test:uiux-u7`: **6/6 Node + 23/23 Browser**.
- visual regression المستقل بعد تثبيت الصور: **10/10**.
- performance gate تحت CPU ×4 مكرراً: **3/3**.
- `npm run check`: **272/272 Node + 75/75 Browser**.
- `npm run check:clean`: **272/272 Node + 75/75 Browser** بعد `npm ci` في
  snapshot معزول، ثم ثبت أن شجرته النظيفة بقيت بلا تغييرات بعد الاختبارات.
- JavaScript syntax: 136 ملفاً؛ HTML/CSS standards: ناجحة.
- `docs/uiux-u0/card-assets.sha256` و
  `docs/uiux-u0/protected-files.sha256`: مطابقان بايتاً ببايت.

## التحقق البشري المؤجل

بقرار مالك المنتج لم تُنفذ الاختبارات البشرية أثناء الشرائح. أصبحت
`UIX-H01`–`UIX-H14` جاهزة للتنفيذ المجمع على هذه الواجهة في
`docs/DEFERRED-VALIDATION-REGISTER.md`. لذلك الحالة الصادقة هي
**Engineering Complete / Human Validation Deferred** وليست `Validated`، ولا
يبدأ P1-H01 قبل إغلاق البنود المانعة هناك.

## الرجوع

الرجوع الكامل يكون إلى رأس `codex/uiux-u6-feedback`. لا migration لبيانات
اللعبة. لأن UIX-7 تحذف `style.css` والـflag نهائياً، فالرجوع الجزئي لملف واحد
غير مدعوم؛ إما النظام الجديد كاملاً أو رأس UIX-6 كاملاً.
