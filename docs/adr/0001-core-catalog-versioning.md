# ADR-0001: فصل قواعد اللعب عن كتالوج البطاقات

- الحالة: مقبول
- التاريخ: 2026-08-28

## السياق

قلب «مِهْ» ثابت، بينما ستصدر بطاقات جديدة دوريًا. خلط القواعد والتعريفات يجعل
كل إضافة مخاطرة بإعادة تفسير مباراة قديمة أو تغيير الرزمة الأساسية ضمنيًا.

## القرار

- `MEH_CORE_MANIFEST.rulesVersion` يصف قواعد الدور، المطابقة، السحب والفوز.
- `MEH_CATALOG_MANIFEST.catalogVersion` يصف تعريفات البطاقات فقط.
- `deckRecipeId` يحدد التركيبة الدقيقة للرزمة؛ الرزمة الكلاسيكية هي
  `classic-60-v1` وتبقى مرجع النسخة الحالية.
- تعريف البطاقة بيانات مقيدة بـ`effectOpcode` مسموح، وليس JavaScript قابلًا
  للتنفيذ يأتي من المتجر أو الشبكة.
- أي تغيير في القواعد يرفع `rulesVersion`، وأي تغيير محتوى يرفع
  `catalogVersion`، وأي تغيير تركيبة ينشئ وصفة جديدة.

## النتائج

يمكن إعادة مباراة ومعرفة العقد الذي حكمها، ويمكن تعطيل محتوى جديد دون تغيير
القلب. كلفة القرار هي إدارة توافق الإصدارات ووصفات الرزم صراحة.
