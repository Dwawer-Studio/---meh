# UIX-0 — Motion and feedback storyboard

الحالة: عقد مرجعي قبل التنفيذ. لا تحتوي هذه الوثيقة على أي تغيير لقواعد اللعب.

## 1. لعب بطاقة عادية

| الزمن | الصورة | السبب/النتيجة | الصوت واللمس |
|---:|---|---|---|
| 0ms | البطاقة تستجيب بالضغط 2px وتظهر حافة حبرية | إقرار فوري بأن اللمس وصل | `tap-soft` اختياري |
| 80ms | ترتفع 10px فوق اليد وتبقى الطاولة مرئية | تثبيت الاختيار قبل التنفيذ | لا شيء |
| 140ms | عند التأكيد تبدأ مسارًا قصيرًا منحنيًا نحو المرمي | ربط مصدر الفعل بنتيجته | احتكاك ورق قصير |
| 260ms | تستقر فوق المرمي، ثم يتغير اللون/الشخصية المسموح بها | النتيجة بعد السبب، لا قبله | `card-settle` + haptic خفيف |
| 340ms | يتحرك مؤشر «الدائرة الحيّة» إلى المقعد التالي | توضيح انتقال الدور | طرق طاولة خافت |
| ≤420ms | يعود الإدخال كاملًا، ويمكن قطع الحركة عند رسالة الشبكة | لا animation تحجب اللعب | — |

في `prefers-reduced-motion`: لا مسار مكاني. البطاقة تتلاشى من اليد وتظهر في
المرمي خلال 120ms، ثم ينتقل outline الدور فورًا.

## 2. عقوبة أو سحب

1. خلال 0–80ms يتأكد اختيار البطاقة ولا يبدأ احتفال.
2. يظهر شريط سبب واحد قرب اللاعب المتأثر: «اسكت اسكت — اسحب بطاقتين».
3. تتحرك بطاقتا السحب واحدة تلو الأخرى خلال 220–380ms؛ عداد اليد يتغير مع كل
   بطاقة، وليس دفعة بلا تفسير.
4. يبقى زر «ليش صار كذا؟» ظاهرًا لمدة 3 ثوانٍ أو حتى الفعل التالي.
5. haptic العقوبة نبضتان خفيفتان؛ لا يستخدم vibration طويلًا ولا وميضًا.

في تقليل الحركة: يتغير العداد `+2` مع نبض حد واحد ويظهر السبب نصيًا.

## 3. انتقال الدور

| العنصر | السلوك |
|---|---|
| المقعد السابق | يفقد التعبئة الحبرية خلال 120ms ويبقى اسمه مقروءًا |
| المسار الدائري | يقطع أقصر قوس قانوني في 180ms، ويعكس الاتجاه عند يوتيرن |
| المقعد الجديد | outline أحمر ثم تعبئة حبرية؛ يظهر رمز اتجاه مستقل عن اللون |
| اللاعب المحلي | feedback بصري دائم، وصوت/haptic فقط إن اختاره المستخدم |
| التطبيق بالخلفية | لا يعيد choreography قديمة عند الرجوع؛ يعرض الحالة الحالية مباشرة |

الانتقال لا يغير مؤقت الدور ولا يؤخر بدءه. المؤقت مصدره حالة المباراة، والحركة
مجرد عرض يمكن إلغاؤه.

## 4. نهاية الجولة والفوز

1. آخر بطاقة تستقر أولًا؛ لا تظهر النتيجة قبل فهم سبب الفوز.
2. خلال 260ms تنكمش الطاولة إلى دائرة Dwawer، ثم تفتح سطح الورق الفاتح.
3. يظهر الفائز والسبب المختصر، ثم حصيلة المجلس، ثم تاماشي المكتسبة.
4. لا تتطاير عملات ولا تظهر مكافأة غامضة؛ المصدر مكتوب «لعب + مشاركة».
5. CTA «مرة ثانية» يصبح قابلًا للمس خلال 420ms كحد أقصى.
6. جاهزية اللاعبين تعيش في نفس الشاشة، ولا تعيد المجموعة إلى ردهة جديدة.

في تقليل الحركة: قطع مباشر بين الطاولة والنتيجة مع cross-fade قدره 120ms.

## 5. مفردات الصوت واللمس

| الرمز | الاستخدام | الحظر |
|---|---|---|
| `tap-soft` | لمس نظامي | لا يتكرر عند السحب المستمر |
| `card-lift` | اختيار صالح | لا يعمل للبطاقة الممنوعة |
| `card-settle` | استقرار البطاقة | لا صوت معدني/كازينو |
| `turn-ready` | أصبح دورك | مرة واحدة وبموافقة المستخدم |
| `penalty-double` | عقوبة ذات نبضتين | لا يزيد عن 250ms |
| `round-resolve` | نهاية الجولة | لا يغطي كلام اللاعبين أو قارئ الشاشة |

الصوت وhaptics تعزيز اختياريان فقط؛ كل معنى له بديل بصري ونصي كامل.
